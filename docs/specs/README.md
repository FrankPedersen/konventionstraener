# Specer

Konventionstrænerens specer. De ligger på GitHub, men ikke på www.kontraktbridge.dk, fordi `_config.yml` udelukker `docs/` og `SPEC-*.md` (Franks valg 27. oktober 2026). En ny spec kan ligge i roden, mens den er i arbejde, og flyttes hertil, når den er færdig.

- [SPEC-konventionskort.md](SPEC-konventionskort.md) – konventionskortene (skabelonen `konvention/2`) til alle trænere på Træn, med Franks afgørelser under Afklaret (17. oktober 2026).
- [SPEC-traen-side.md](SPEC-traen-side.md) – forsiden Træn med alle trænere ordnet efter emne og søgning; aftalerne står på Mine makkeraftaler (17. oktober 2026).
- [SPEC-truscott-traener.md](SPEC-truscott-traener.md) – Truscott 2NT som selvstændig træner med system "generel" (17. oktober 2026).
- [SPEC-sprog-og-ordbog.md](SPEC-sprog-og-ordbog.md) – husets fagord, stavekontrollen og linket til Bridgeordbog; fælles for de tre repoer (22. oktober 2026).
- [SPEC-crowhurst-traener.md](SPEC-crowhurst-traener.md) – Forsvar mod Multi 2♦ (Crowhurst): konventionskort og træner (23. oktober 2026).
- [SPEC-skrifttyper-fast.md](SPEC-skrifttyper-fast.md) – `tools/tjek_skrifttyper.mjs` som fast test af skrifttyperne uden pixelsammenligning med `v-foer-skrifttyper` (28. oktober 2026).
- [SPEC-beskrivende-form.md](SPEC-beskrivende-form.md) – instruktioner og forklaringer i beskrivende form på forsiden, i trænerne og i trænerbeskrivelserne, og testen `tools/tjek_bydeform.py`; listen står i `docs/beskrivende-form.md` (31. oktober 2026).
- [SPEC-makker2-aftaler.md](SPEC-makker2-aftaler.md) – to Makker 2-aftaler: ny højere farve på 2-trinnet 12–15 og spring 16+ (krav i én runde), 3♠ efter 1♥ – 1NT, revers fravalgt og taget af Træn, og svarene på makkers konkurrencedobling (31. oktober 2026).

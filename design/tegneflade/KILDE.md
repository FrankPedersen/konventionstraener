# Skærme fra tegnefladen

Hentet 17. oktober 2026 fra tegnefladen "Ny struktur for trænerne"
https://claude.ai/artifact/Y9sKNd1KgmKQtHTVr2mMAw (version 1792233099-b863).
Rettet samme dag, så skærmene viser forsiden, som den blev bygget (tegnefladens version 1792237796-f8c7):
den fulde sidefod og indledning på mobil, "Læs forslagene" for Forslag, kortene åbner i samme vindue,
og links går til www.kontraktbridge.dk.

`ds/subtlegradient/` er designsystemet Subtle Gradient, som skærmene bruger (`tokens.css`, `tokens.json` og `components/bundle.css` med bl.a. `sg-footer`).

Filerne er en kopi. Ændres tegnefladen, er det den, der gælder. Claude Code kan hente skærmene igen direkte fra linket ovenfor.
